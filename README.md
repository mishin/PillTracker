# 💊 PillTracker (Трекер лекарств)

Android-приложение для удобного отслеживания графика приёма лекарств, контроля длительности курса и получения своевременных напоминаний.

## ✨ Основные возможности
- **Учёт лекарств**: Добавление препаратов с указанием времени приёма и длительности курса.
- **Умные напоминания**: Точные будильники (`AlarmManager`) срабатывают даже в режиме энергосбережения (Doze Mode).
- **Ежедневный сброс**: В полночь автоматически снимаются галочки о приёме (через `WorkManager`).
- **Восстановление после перезагрузки**: Будильники автоматически перепланируются при включении устройства (через `BootReceiver`).
- **Импорт из Excel / Google Таблиц**: 
  - Загрузка графика из локального `.csv` файла.
  - Прямой импорт по ссылке из **Google Таблиц** (без необходимости скачивать файл).
- **Умный парсер**: Автоматически распознаёт текстовое время (например, «Утро (за 30 мин до завтрака)» → 07:30) и вычисляет старт курса по дате из заголовка таблицы.

## 🛠 Технологический стек
- **Язык**: Kotlin
- **UI**: Jetpack Compose (Material Design 3)
- **Архитектура**: MVVM (ViewModel + StateFlow)
- **База данных**: Room (SQLite)
- **Фоновая работа**: WorkManager, AlarmManager, BroadcastReceiver
- **Сеть**: Встроенный `java.net.URL` (для загрузки CSV из Google Docs)
