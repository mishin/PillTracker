# Техническое задание (ТЗ)  
## Мобильное приложение "SyncFTP Camera" для Android

### 1. Цель разработки
Разработать простое Android-приложение, которое:
- Позволяет настроить подключение к FTP/SFTP серверу.
- Открывает камеру устройства.
- Делает фото с **минимальным качеством** (маленький размер файла).
- Автоматически сохраняет полученное фото в заданную папку на FTP/SFTP сервере.
- Отображает статус подключения и результат отправки.

---

### 2. Основные функции

#### 2.1 Экран настроек
Пользователь должен иметь возможность ввести и сохранить следующие параметры:

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Протокол** | Выбор (FTP / SFTP) | Переключатель между FTP и SFTP |
| **Сервер** | Текст (строка) | IP-адрес или доменное имя сервера |
| **Порт** | Число | 21 для FTP, 22 для SFTP (по умолчанию) |
| **Логин** | Текст | Имя пользователя |
| **Пароль** | Текст (скрытый) | Пароль |
| **Папка на сервере** | Текст | Путь к папке для сохранения фото (например `/uploads/`) |
| **Локальная папка** | Текст (необязательно) | Для временного хранения (опционально) |
| **Состояние** | Текст | Статус подключения / последней операции |

Все настройки должны сохраняться между сеансами.

#### 2.2 Экран камеры
- Кнопка **«Открыть камеру»**.
- После нажатия открывается стандартное системное приложение камеры или встроенный CameraX (простой режим).
- Фото делается с **минимальным качеством / сжатием**:
  - Разрешение не выше 640x480 пикселей.
  - Сжатие JPEG с качеством 30–50%.
  - Итоговый размер файла: **до 100–150 КБ**.
- После подтверждения фото сохраняется во временную локальную папку.

#### 2.3 Отправка на сервер
- После получения фото приложение автоматически:
  - Подключается к серверу по FTP/SFTP (согласно сохранённым настройкам).
  - Загружает файл в заданную серверную папку.
  - Имя файла должно быть уникальным, например:
    - `photo_YYYYMMDD_HHMMSS.jpg`
    - или с использованием UUID.
- Отображать статус: `"Отправка..."`, `"Успешно"`, `"Ошибка: ..."`.
- После успешной отправки локальный временный файл удаляется.

#### 2.4 Статус и логирование
- Внизу экрана (или в отдельном поле) отображать:
  - Текущий статус подключения (подключён / нет).
  - Результат последнего действия (фото сохранено, отправлено, ошибка).
- Простой текстовый лог последних событий (3–5 строк).

### 3. Технические требования

| Категория | Требование |
|-----------|-------------|
| **Язык** | Kotlin |
| **Минимальная версия Android** | API 24 (Android 7.0) |
| **UI** | Jetpack Compose (Material 3) |
| **Камера** | CameraX (простой ImageCapture с низким качеством) или Intent `MediaStore.ACTION_IMAGE_CAPTURE` с уменьшением размера |
| **FTP/SFTP** | Apache Commons Net (FTP) + JSch (SFTP) |
| **Сохранение настроек** | DataStore Preferences |
| **Разрешения** | `CAMERA`, `INTERNET`, `WRITE_EXTERNAL_STORAGE` (только для временного файла) |
| **Асинхронность** | Kotlin Coroutines |

### 6. Порядок работы (User Story)

1. Пользователь открывает приложение.
2. Вводит настройки сервера (один раз).
3. Нажимает **«Открыть камеру»**.
4. Делает фото (встроенная камера).
5. Фото автоматически сжимается до минимального качества.
6. Приложение подключается к серверу по FTP/SFTP.
7. Фото загружается в указанную папку.
8. На экране появляется сообщение об успехе или ошибке.

---

### 7. Требования к коду (для генерации нейросетью)

- Использовать готовые библиотеки:
  - `androidx.camera:camera-core:1.3.0`
  - `androidx.camera:camera-camera2:1.3.0`
  - `androidx.camera:camera-lifecycle:1.3.0`
  - `androidx.camera:camera-view:1.3.0`
  - `commons-net:commons-net:3.10.0`
  - `com.github.mwiede:jsch:0.2.16`
  - `androidx.datastore:datastore-preferences:1.0.0`
- Реализовать сжатие изображения **перед отправкой**.
- Не хранить фото в галерее телефона (только временно в кэше).
- Код должен быть полностью самодостаточным (без ручных правок после генерации).

---

### 8. Ограничения

- Фото делается **только** через кнопку в приложении (без фонового режима).
- Приложение **не требует** синхронизации по событию «новый файл в папке» — эта часть удаляется.
- Приложение **работает только в активном режиме** (не фоновый сервис).

### 10. Проверочные вопросы (чтобы нейросеть точно поняла задачу)

> ❓ В каком качестве сохранять фото?  
> **→** Минимальное: 640x480, JPEG качество 40%, размер ~100 КБ.

> ❓ Куда сохранять на сервере?  
> **→** В папку, указанную в настройках (например, `/photos/`).

> ❓ Что делать с локальным файлом после отправки?  
> **→** Удалить.

> ❓ Нужна ли поддержка FTP и SFTP одновременно?  
> **→** Да, переключатель в настройках.
